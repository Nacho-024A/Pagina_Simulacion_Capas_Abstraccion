Simulador de Flujo

Escribe un mensaje y observa cada paso que ocurre desde que presionas "Enviar" hasta que llega al destinatario.

📱 Tu dispositivo (emisor)
📱
Capa de Aplicación
WhatsApp llama a Enviar_mensaje()
Presionas "Enviar". La app toma tu texto y lo pasa a la función responsable de enviarlo.
☕
Lenguaje de Programación — Java / Kotlin
Enviar_mensaje(texto, destinatario)
El código de WhatsApp empaqueta el mensaje: le añade tu número, el del destinatario y la hora.
🖥️
Sistema Operativo — Android / iOS
El SO delega al módulo de red
El SO recibe la orden y la pasa al controlador de red del dispositivo para que lo transmita.
⚡
Lenguaje Máquina — Binario
El mensaje se convierte en 0s y 1s
Cada letra se transforma en su código binario. El hardware solo entiende este lenguaje.
📡
Hardware — Antena / WiFi
Los transistores transmiten la señal
Miles de millones de transistores convierten los bits en señales eléctricas o de radio que viajan por la red.
🌐 Internet
🌐
Red — Servidores de WhatsApp
La señal viaja por Internet
Los paquetes de datos saltan entre routers y servidores hasta llegar al servidor de WhatsApp.
📲 Dispositivo receptor
📡
Hardware — Antena / WiFi
La señal llega al dispositivo
La antena del receptor capta la señal. Los transistores la convierten de nuevo en bits.
🖥️
Sistema Operativo
El SO entrega los datos a WhatsApp
El sistema operativo del receptor identifica que los datos son para WhatsApp y se los pasa.
☕
Lenguaje de Programación — Java / Kotlin
Recibir_mensaje(datos)
WhatsApp en el receptor llama a su función de recepción, que desempaqueta los datos.
📲
Capa de Aplicación
¡El mensaje aparece en pantalla!
WhatsApp muestra la burbuja del mensaje, reproduce la notificación y marca el doble check.

El mensaje completó su viaje en milisegundos
